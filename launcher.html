A profile is a name for a SillyTavern folder. Switch profiles to run another SillyTavern — another version, a test copy, or one with other characters. Each folder keeps its own chats, characters and settings.

Profiles

—

SillyTavern on another computer

A SillyTavern running on another PC, a home server or a VPS. It opens as a tab in the SillyTavern window with its own login; this PC's SillyTavern keeps running as it is. Updates, backups and migrating happen on that computer.

Not encrypted: this is a plain http:// address outside your home network, so your password and chats would travel readable. Use https:// or a private network such as Tailscale if you can.

The login is for SillyTavern's basic auth (its "listen" mode with a password); it's saved encrypted with Windows' own protection. If SillyTavern shows its own login page instead, sign in there once — the tab remembers it.

Switching restarts the server on the new folder and reloads open SillyTavern tabs. Open next to it runs another profile at the same time, on its own port, in a new tab. Removing a profile never deletes its folder. You can also switch from the top bar here, the tray icon, or the SillyTavern window's menu.

Copy characters, chats, presets, extensions and more from one SillyTavern to another, or between users. The source is never changed, and every migration can be undone.

Chrome extensions

Loading…

Chrome extensions only partly work outside Chrome: this app gives them most of what they use (buttons and popups, right-click entries, tabs, storage, notifications), but not everything. Each one says what it can't use here. They run in your SillyTavern pages (also other installs and other computers, not the read-only copy) and can read what you type there, so only add ones you trust. They update themselves from the Chrome Web Store.

Add-ons for this app itself (not for SillyTavern): they can add entries to the right-click menu and the window's menu, add features to SillyTavern pages, and show a panel here. Anyone can make one: each is a folder with a manifest.json.

Desktop extensions

Extensions run with full access to your PC, like any program, so they stay off until you turn them on. Only turn on extensions you trust. Edited an extension? Click Reload.

Third-party extensions installed in SillyTavern: see how each one was rated for safety, update them together (and undo that), find new ones, and save your set as a Kit to use in another SillyTavern.

Installed extensions

Kits

A Kit is a saved list of extensions (their addresses and versions, not their files). Use it to set up the same extensions in another profile, or share it as a file.

Userscripts

Some extensions need a companion .user.js script (normally installed in Tampermonkey). This app runs them itself — drop them in the userscripts folder and restart.

Back end

Installs the latest Node.js (LTS) and Git with Windows' package manager, then reinstalls SillyTavern's dependencies so everything matches.

Health check

Repair tools

Install missing dependencies

Fixes "Cannot find module" errors, usually after an update. Safe to run any time.

Reset package-lock.json

The most common reason an update fails. Restores the official file so updating works again.

Reinstall dependencies

Deletes node_modules and downloads everything again. For stubborn errors. Takes a few minutes.

If this app stops working

A new SillyTavern version might not work with this app right away. You can always use SillyTavern the usual way:

Open in my browser

Starts the server if needed and opens SillyTavern in your normal web browser instead of this app's window.

Start the classic way

Runs SillyTavern's own Start.bat in a command window, without this app. Close that window to stop it.

This app can live anywhere — it remembers where SillyTavern is. Move relocates the whole install, backups included.

Server

The port is passed to the server on start, overriding config.yaml. Changes apply the next time the server starts.

Behavior

SillyTavern window

On top keeps SillyTavern above every other app. In background keeps it behind other apps, even while you use it — handy for a full-screen SillyTavern under your other windows. Normal is the default. All three are also in the right-click menu of the window's top bar.

F11 toggles full screen. In full screen, move the mouse to the top edge to show the bar. Drag tabs to reorder them, or out of the bar into a window of their own.

Phone & tablet

With a password, other devices must sign in; this app signs in by itself. Anyone on your Wi-Fi could open SillyTavern without one, so set one unless you trust everyone on it. SillyTavern's own config.yaml is never changed.
