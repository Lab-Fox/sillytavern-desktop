Quick access

Recent activity

Backups zip your data folder: characters, chats, settings, presets and extensions. One is made automatically before every update. Restoring never deletes anything — your current data is moved aside first.

Saved backups

Add-ons for this app itself (not for SillyTavern): they can add buttons to the top bar's menu, change how SillyTavern pages look, and show a panel here. Each one is a folder with a manifest.json.

Desktop extensions

Extensions run with full access to your PC, like any program, so they stay off until you turn them on. Only turn on extensions you trust. Edited an extension? Click Reload.

Third-party extensions installed in SillyTavern. Extensions installed from SillyTavern's own menu can be updated here in one go. Install new ones from the Extensions menu inside SillyTavern.

Installed extensions

Userscripts

Some extensions need a companion .user.js script (normally installed in Tampermonkey). This app runs them itself — drop them in the userscripts folder and restart.

Back end

Installs the latest Node.js (LTS) and Git with Windows' package manager, then reinstalls SillyTavern's dependencies so everything matches.

Health check

Repair tools

Install missing dependencies

Fixes "Cannot find module" errors, usually after an update. Safe to run any time.

Reset package-lock.json

The most common reason an update fails. Restores the official file so updating works again.

Reinstall dependencies

Deletes node_modules and downloads everything again. For stubborn errors. Takes a few minutes.

Server

Behavior

SillyTavern window

On top keeps SillyTavern above every other app. In background keeps it behind other apps, even while you use it — handy for a full-screen SillyTavern under your other windows. Normal is the default. All three are also in the right-click menu of the window's top bar.

F11 toggles full screen. In full screen, move the mouse to the top edge to show the bar.
